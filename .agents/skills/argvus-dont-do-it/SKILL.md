# ARGVUS Don't do it Workflow

Use this skill to finish:

- DO NOT commit.
- DO NOT push.
- DO NOT build. Use the project's `make check`.
- DO NOT use `git reset`.
- DO NOT alter the documentation in `web/site-src`.
