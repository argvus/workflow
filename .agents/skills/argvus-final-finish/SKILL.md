# ARGVUS Final Finish Workflow

Use this skill to finish:

- Update or implement the changes in the documentation (if necessary).
- List the projects that were modified.
- Include the commit messages for each project where changes were made. The messages must follow the conventional commit format (using `feat:`, `fix:`, `chore:`, `docs:`, etc.) and include a description. For example:

```sh
feat: new implementation for X

- A new implementation was carried out for X...
```
